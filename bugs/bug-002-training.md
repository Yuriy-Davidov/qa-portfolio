# Баг-репорт №002 (учебный)

## Общая информация
- **ID бага:** BUG-002
- **Название:** Отсутствует подтверждение пароля при регистрации
- **Серьезность:** Major
- **Приоритет:** High
- **Окружение:** Google Chrome 120, Windows 11
- **Компонент:** Форма регистрации

---

## Шаги для воспроизведения
1. Открыть страницу регистрации
2. Ввести пароль "qwerty123" в поле "Пароль"
3. Ввести другой пароль "qwerty456" в поле "Подтверждение пароля"
4. Нажать кнопку "Зарегистрироваться"

---

## Фактический результат
Система принимает разные пароли и регистрирует пользователя

## Ожидаемый результат
Система должна показать ошибку: "Пароли не совпадают"
