# Баг-репорт №001 (учебный)

## Общая информация
- **ID бага:** BUG-001
- **Название:** Отсутствует валидация поля ввода номера телефона
- **Серьезность:** Major
- **Приоритет:** High
- **Окружение:** Google Chrome 120, Windows 11
- **Компонент:** Форма регистрации

---

## Шаги для воспроизведения
1. Открыть страницу регистрации
2. В поле "Номер телефона" ввести значение "123"
3. Нажать кнопку "Продолжить"

---

## Фактический результат
Система принимает номер телефона из 3 цифр и переходит на следующий шаг без ошибки

## Ожидаемый результат
Система должна показать сообщение об ошибке: "Введите корректный номер телефона (10 цифр)"
