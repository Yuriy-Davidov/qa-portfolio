# Тест-кейсы для формы поиска (пример)

## TC-001: Проверка поиска по существующему товару
| **Атрибут** | **Значение** |
|-------------|---------------|
| **ID** | TC-001 |
| **Название** | Поиск по существующему товару |
| **Предусловие** | Открыта главная страница сайта |
| **Шаги** | 1. Ввести в поисковую строку "телефон"<br>2. Нажать Enter |
| **Ожидаемый результат** | Отображаются товары, содержащие слово "телефон" |
| **Статус** | Pass / Fail |

## TC-003: Проверка поиска с пустым запросом

|-------------|---------------|
| **ID** | TC-003 |
| **Название** | Поиск с пустым запросом |
