# Тест-кейсы для формы регистрации (учебные)

## TC-001: Регистрация с валидными данными
| **Атрибут** | **Значение** |
|-------------|---------------|
| **ID** | TC-001 |
| **Название** | Регистрация с валидными данными |
| **Предусловие** | Открыта страница регистрации |
| **Шаги** | 1. Ввести телефон "9123456789"<br>2. Ввести email "test@mail.ru"<br>3. Ввести пароль "Qwerty123!"<br>4. Нажать "Зарегистрироваться" |
| **Ожидаемый результат** | Пользователь зарегистрирован, появилось сообщение "Регистрация успешна" |
| **Статус** | Pass / Fail |
